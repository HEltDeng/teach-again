# 需求文档 — 再教我一次

## 里程碑 1：悬浮球基础
- R1.1 安装启动，引导授予悬浮窗权限（Settings 跳转）
- R1.2 前台服务 + 持久通知，常驻后台
- R1.3 可拖动悬浮球，打开微信后仍显示
- R1.4 点球展开步骤卡（当前步骤文字+进度）
- R1.5 操作按钮：我做到了 / 上一步 / 再说一遍(TTS) / 暂停 / 关闭
- R1.6 仅球/卡区域接收触摸，不阻塞微信点击
- R1.7 完成全部步骤给予温暖文字反馈
- R1.8 进度 SharedPreferences 持久化，重启恢复
- R1.9 旋转/权限拒绝/撤销不崩溃，服务重复启动安全

## 里程碑 2：父母端首页 + 教程
- R2.1 首页：大字体、大按钮、暖米白+橙色/珊瑚色
- R2.2 3 个内置教程：微信调大字体、给家人发照片、发起视频通话
- R2.3 每步说明：在哪个 App、点哪里、看到什么
- R2.4 系统中文 TTS 朗读步骤
- R2.5 "家人教一次"：选任务/称呼 → 生成可编辑分步教程 → 本地保存
- R2.6 系统分享/粘贴导入教程文本，带格式校验和长度限制
- R2.7 教程生成用本地模板，界面标注"生成步骤"，不宣称在线 AI
- R2.8 所有数据本机存储，离线可用

## 里程碑 3：单句聊天生成 + 泛化
- R3.1 单输入框聊天页：老人说一句话即生成步骤，不分字段
- R3.2 整句识别已知应用复用模板；未知任务给待补全草稿，不可直接跟学
- R3.3 结果可一键开始跟学（有权限直启服务），也可修改
- R3.4 连续反馈上下文（"这一步找不到"）；新任务清理旧上下文
- R3.5 无 Key 的纠错反馈温和说明本机模板局限，不重复假装解决
- R3.6 IME 自带语音输入，不录音、不申请麦克风权限

## 里程碑 4：模型接入（可配置，默认不联网）
- R4.1 DeepSeek/OpenAI/兼容接口，Base URL/Model/密码式 Key，可空保存、可清除
- R4.2 Key 用 Keystore AES-GCM 加密，按供应商+域名隔离，不跨域发送
- R4.3 HTTPS /chat/completions 非流式，禁重定向、超时、取消、大小上限、友好 401/429
- R4.4 严格校验模型 JSON（2–20 步、长度），拒绝 builtin、不覆盖内置
- R4.5 当前不使用真实 Key；接入代码就绪，填 Key 后可用
- R4.6 配置 Key 后无网络时直接提示网络错误，不自动降级到本地模板

## 里程碑 5：画面识别 OCR（仅微信、可选、默认关闭）
- R5.1 在自动跟随基础上可选开启；默认关闭
- R5.2 Android 14+ 用 takeScreenshotOfWindow 只截当前微信窗口
- R5.3 捆绑 MLKit 中文模型本机识别；不保存图片、不打印文字、不上传
- R5.4 单任务 + 间隔≥2 秒；失败回空列表，回调主线程；用完释放 Bitmap/HardwareBuffer
- R5.5 缺截屏能力时提示重新开启无障碍；可随时关闭
