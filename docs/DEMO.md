# 《再教我一次》现场验收

这份清单用于真机检查。未运行的项目不标为通过；构建成功不等于界面验收通过。

## 第一条必须跑通的流程

1. 在荣耀手机安装调试 APK，打开应用。
2. 选择一个教程，按应用指引进入系统悬浮窗权限页。
3. 拒绝权限后返回：应用保留明确的重试入口，不崩溃。
4. 允许权限后启动陪伴：出现“我在”悬浮球和前台服务通知。
5. 打开真实微信：悬浮球继续显示，拖动到边缘不会跑出屏幕。
6. 点球：当前步骤可读；收起卡片：微信其余区域可以正常操作。
7. 点击“我做到了”、上一步、再说一遍、暂停与恢复，确认状态一致。
8. 关闭悬浮助手：球、卡片、服务通知都按预期消失。

## 现场演示顺序（约 90 秒）

1. 打开首页的聊天入口，在一个输入框里输入“我想用相机拍照”；也可使用手机输入法的小话筒转成文字。
2. 未填 Key 的现场版本明确使用“本地体验”，展示生成后的步骤草稿与可编辑预览。
3. 保存并开始跟学，切换到目标应用，展示“我在”跨应用悬浮、拖动、中文朗读和逐步确认。
4. 用“微信调大字体”展示已有页面规则的自动跟随；没有真实验证成功前，不把此项写成演示保证。
5. 展示模型设置，可选择 DeepSeek / OpenAI / 兼容接口，Key 留空。说明填入本地 Key 后才会请求所选模型。
6. 展示家人分享/导入入口，以及 Kiro 的需求、设计、任务、Hook 与验证记录。

演示中不向真实联系人发送消息或发起通话；视频通话与发照片教程展示到最终确认之前。截图优先使用本应用或系统设置，避免把微信联系人、聊天内容作为提交素材。
