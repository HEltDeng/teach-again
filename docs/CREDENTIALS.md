# 凭据、签名与本地配置

本项目归档不提供模型 API Key、账户访问令牌、服务账号凭据或 Android 签名私钥。源码中用于保存 Key 的字段名、Android Keystore 别名及供应商公开地址是程序配置标识，不是可用于登录的凭据。

## 使用者如何配置

- 默认使用本地模板，无需模型账户或 Key。
- 需要模型生成时，在 Android 应用的“模型设置”中填写自己的供应商地址、模型和 Key，并自行验证；不要把 Key 写进 Java、Gradle、README 或提交记录。
- Key 通过设备自己的 Android Keystore 加密保存，按供应商和目标域名隔离。可以在应用设置中清除当前域名下保存的 Key。
- Android SDK 路径放在未提交的 `local.properties` 中，例如 `sdk.dir=/path/to/Android/sdk`。
- `assembleDebug` 使用本机自动生成的调试签名。不同机器的调试签名可能不同，安装包更新兼容性应自行检查。正式签名私钥及口令由各自持有人保管，不随仓库交付。
- APK 自带的公开签名证书用于验证安装包签名，不是签名私钥，不能通过删除它来“清理凭据”。

2026-10-25 归档检查对源文件、已有提交内容和保留归档进行了常见密钥/令牌模式、私钥标记及敏感文件名检查，未发现需撤销的真实凭据。此记录描述本次检查范围，不是对所有可能秘密形式的绝对保证。

若日后发现真实凭据曾进入仓库，应先在对应服务撤销或轮换，再处理相关提交历史和副本；只删除当前文件并不能使已经泄露的凭据失效。
