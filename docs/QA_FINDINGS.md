# 《再教我一次》验收记录

更新：2026-10-24 15:18。代码检查、主机测试、真机观察分别记录；未测项目不记为通过。

## 已修复并检查

- 微信字体教程采用现场手机路径：我 → 设置 → 界面与显示 → 字体大小。旧版「通用」仅作为兼容提示，不再当作新版必点入口。
- 悬浮球保持独立，卡片紧凑可滚动；拖动限制在可见区域。用户此前确认悬浮球、卡片和中文朗读的问题已经解决。
- 「找不到」暂停自动推进，保留当前步骤；「回到这一步」不偷偷跳到下一步。「问一问」携带教程 ID 和步骤进入聊天页。
- 无障碍服务在用户关闭自动跟随、暂停、结束或不存在学习任务时，不遍历屏幕节点；不执行点击或手势。
- 详情页的空教程保护、完成后重新开始、启动提示硬编码微信已修正。
- 配置按供应商和接口来源隔离密钥，使用 Android Keystore 加密保存；请求限定 HTTPS，禁止重定向，有连接/读取超时及响应大小限制。仅代码审查，未填真实 Key。
- 生成与导入校验标题、步骤数和字段长度；外部教程不能覆盖内置身份。
- 聊天入口已从两个字段改为单句输入；语音入口使用手机输入法，不新增录音权限。

## 收尾重点

- 无 Key 的本地反馈必须承认模板能力边界，不把用户「找不到」误当成成功纠错。
- 普通未知任务必须显示待补全，不能把整句话当作应用名，也不能直接开始占位教程。
- 验证聊天、保存、悬浮、求助的整条流程；验证空 Key 模型设置持久化。
- 生成教程是可编辑副本；自动跟随规则目前按已定义教程匹配，不能宣传任意应用自动识别。
- 最终发布材料必须附 APK、可重建源码、Kiro specs/steering/hooks 和真实验证结果。排除本机路径、构建缓存与密钥。
